and one stop that came off the route. Channels were read from each venue's own site on

## The stops

**Confirm:**
- **Opening time.** The database says 07:30. The shop's own site says 8am, Tuesday to
  Saturday. The route starts at 08:00, so it holds under either, but the row should

**Channel:** phone +1-604-731-3528 · **email patisserielebeau@gmail.com**. The site also

## The short answer on channels

**Email works for four of the five stops**: Lebeau, 49th Parallel, Chewies and The Naam
all publish an address. **Sophies is phone only.**

Two confirmations are the kind only a person can answer: whether Lucky's Doughnuts
actually trades inside 2198 West 4th, and how long the queue at The Naam runs at seven.
The doughnut question matters most — the stop's name carries it and the copy does not,
so the name on the listing page and the name in the route must be settled together.

## The stop that came off

**Au Comptoir** (2278 West 4th) held the lunch slot in the first draft. Its own site
lists **Tuesday as closed** while the database has it open daily 08:00–22:00, so it
failed the Tuesday test the routes run on, and Sophies took the slot. The database row
still needs correcting. Until it is, this route and the listing page will disagree
about the restaurant's Tuesday.
